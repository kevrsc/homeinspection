## Epic summary

Epic 6 delivers the **Phase 2** optional path: after a successful **`POST /v1/report/upload`**, the homeowner may invoke **`POST /v1/report/summarize`** from **`/results`** with the **same JSON shape** as upload success, **shared auth**, structured errors via **`UploadErrorPanel`**, and **NFR1-aligned** progress copy. **Story 6.2** (multipart PDF single-shot to summarize) remains **backlog** by design in `epics.md` until product asks for a contract extension.

| Story | Outcome |
|-------|---------|
| **6.1** | **Done** — `summarizeEndpoint`, `summarizeReport` client, `AiSummarySection`, tests, README, a11y mock |
| **6.2** | **Backlog** — optional future API; not required to close the epic |

**Delivery:** 1/1 in-scope stories **`done`**.

---

## What went well

- **Clear contract boundary:** Singular **`/v1/report/summarize`**, JSON body only, reuses upload auth and error envelope patterns—minimal surprise for integrators.
- **Reuse over novelty:** `parseUploadFailure`, `UploadErrorPanel` variant for summarize, `readWebConfig` lazy init aligned with upload.
- **End-to-end validation loop:** LLM path hardening (parser, Ollama `format`, debug logging **`LLM_DEBUG_LOG`**) landed in the API while the web story was in review, improving real-device success without bloating the web diff.

---

## Challenges and friction

- **Non-deterministic LLM output:** Required iterative parser tolerance and optional **JSON Schema `format`** on Ollama; teams should keep **`LLM_DEBUG_LOG`** off in shared environments.
- **Story 6.2 scope:** Explicitly deferred—document in planning if a one-shot multipart summarize route is ever prioritized.

---

## Key insights

1. **Optional UI must stay optional:** Default results flow unchanged until the user clicks summarize (AC and UX-DR5 coherence).
2. **`pageCount` on summarize body:** Client must send a valid non-negative integer even when upload payload omitted it—documented default (**0**) avoids silent 422s.
3. **Epic closure with backlog child:** **6.2** can remain **`backlog`** while **epic-6** is **`done`** because the epic’s committed scope was **6.1** only; **6.2** is a labeled future extension.
